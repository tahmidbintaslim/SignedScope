Privacy

On the free tier, SignedScope stores no documents, signatures or receipts. Each one is encoded in the link and signed by the server, which keeps no copy. The data sits in the URL fragment (after the #), so it is not sent when the page loads. When you open a link, the page sends the full document to the server so it can check the signature. The server handles it in memory and does not store it.

I store waitlist emails, plus the plan and note you give me, so I can contact you about SignedScope. To rate-limit sign-ups, the waitlist form also keeps a keyed hash of your IP address, not the address itself. If paid plans open, Stripe will process the payments.

If you arrive from a link with a ?ref= tag (for example from a launch post), the server stores one anonymous marker with that tag and the date, so I can see which channels work. It stores no IP address, cookie or browser details. The tag is also saved with a waitlist sign-up.

If you paste a client message and press “Turn into items”, the text is sent to Anthropic’s Claude API to draft the items, when AI drafting is switched on. Anthropic processes it under its commercial terms; SignedScope does not store it. Without AI, a simple rule-based splitter runs on the server instead.

Services that process data for SignedScope: Vercel (hosting and Blob storage for the waitlist and anonymous counters) and Anthropic (AI drafting, only for pasted text).

When a client signs, the receipt records the name and email they enter, the time, their country (from the IP address) and a truncated hash of their browser's user agent. The IP address is not stored.

To remove your waitlist entry, use the contact form and ask me to delete it.
