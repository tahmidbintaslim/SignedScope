# Interview pack (print or keep open during calls)

Full method: `02-validation-kit.md`. This page is just the essentials.

## 1. Pass/fail thresholds: agree these before interview 1

| Gate | Pass if |
|---|---|
| Problem | 10 or more of 20 rate a pain **6 or more** (how often 0–3 × how bad 0–3), and 6 or more name a real amount lost in the last 3 months |
| Lead pain | Scope changes rank top 2 pains in at least one country |
| Understands it | 4 or more of 5 explain the home page after 5 seconds |
| Can use it | 4 or more of 5 send a document without help in under 10 minutes |
| Will pay | 5 or more pay $10 or $20 for a pilot within 2 weeks |

Fail → don't build; change the pain, the segment or the price first.

## 2. Outreach messages (English; have a native speaker adapt for Thai and Bangla)

**Facebook group or LinkedIn post**
> I'm researching how freelance web developers and designers handle client projects, from first message to getting paid. Looking for 20 people for a 30-minute call. Not selling anything. Small thank-you for your time. Comment or DM me.

**Direct message**
> Hi [name], I saw your work on [place]. I'm researching how freelancers handle proposals, client changes and payments. Could I ask you about your last project in a 30-minute call this week? I'm not selling anything. Happy to send a [thank-you] after.

**Follow-up (no reply after 3 days)**
> Hi [name], just checking if you had time for a quick 30-minute chat. If not, no worries at all.

**Confirm a booking**
> Thanks! [Day, time, timezone], [Meet/Zoom link]. I'll ask about your last client project. No prep needed.

## 3. Screener: all must be "yes"

1. Freelancer or studio of 1–5 people?
2. Web development or UI/UX design work?
3. 3 or more client projects in the last 6 months?
4. Do you choose the tools you pay for?
5. Any fixed-price or milestone projects?

## 4. Interview questions (30 minutes)

Ask about real past events. Don't pitch. Write down their words.

**Last project (10 minutes)**
1. Tell me about the last project you won from a new client.
2. What happened from their first message to starting work?
3. How did you make the proposal or quote? How long did it take?
4. Where did the requirements come from? (email, LINE, WhatsApp, a call)
5. How did the client say yes? Was anything signed?
6. How did you ask for payment? How did you know it arrived?

**Extra work (10 minutes, the key part)**

7. Think of the last time a client asked for something extra mid-project. What happened, step by step?
8. Did you charge for it? Why or why not?
9. About how many hours or how much money was it?
10. How often has this happened in the last 3 months?
11. What did you try to stop it happening? Did it work?

**Tools and money (3 minutes)**

12. Which tools do you use for all this? Which do you pay for, and how much?
13. What's the most annoying part of the whole process?

**Show the product (5 minutes)**

14. *(Show the home page for 5 seconds, then hide it.)* What does this do? Who is it for?
15. *(Give this sample message: "Can we add a booking page and 3 more pages?")* Use this to send your client something to approve. *(Watch; don't help.)*
16. What was confusing? What would stop you from using it on a real project?

**Price (2 minutes)**

17. It's $10 a month ($20 for a studio). Want to try it on your next real project as a paid pilot?
   - If "too expensive": *Compared to what? What would make it worth $10?*

Note the highest step they reached:
0 polite only · 1 "send me the link" · 2 "I'll try it on a real project" · 3 says yes to paying · 4 paid.

## 5. Scoring after each call (2 minutes)

| Pain | How often 0–3 | How bad 0–3 | Score (×) |
|---|---|---|---|
| Unpaid extra work | | | |
| Proposals take too long | | | |
| Requirements scattered | | | |
| Hard to get approval or signature | | | |
| Payment tracking | | | |

How often: 0 never · 1 once in 6 months · 2 monthly · 3 most projects.
How bad: 0 none · 1 annoying · 2 lost hours · 3 lost money or a client.
